ReKarver Documents

En développement

L'application sœur de ReKarver, pour les documents plutôt que les photos. Elle récupère les documents supprimés d'un disque, d'une carte mémoire ou d'une clé USB, avec leur nom et leur date d'origine. Comme ReKarver, elle lit le disque sans jamais y écrire.

Prévenez-moi quand elle sera disponible
Ce qu'elle fait

Retrouvez vos documents

  • Retrouve les documents supprimés dont le disque garde encore une trace
  • Les récupère avec leur nom et leur date
  • Affiche ce qu'elle a trouvé sous forme de liste de noms, avec un aperçu, pour que vous choisissiez quoi garder
  • Enregistre les documents récupérés dans le dossier de votre choix
Types de documents
PDF · Word · Excel · PowerPoint · OpenDocument · RTF · texte · CSV · ZIP
Disques
FAT · exFAT · NTFS
Compte requis
Non
